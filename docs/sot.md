# SoT — 범위와 경계

## 1. 이 저장소가 하는 일 / 하지 않는 일

한다:

- MM 환자 FDG PET/CT 에서 병변을 탐지하는 오픈소스 모델들을 같은 데이터로 돌려 비교한다.
- 탐지 결과로 FL-DS score 를 산출하고, 레지스트리와 결합해 PFS 예측까지 잇는다.
- 각 단계의 실행 절차·설정·결과 요약을 문서로 남긴다.

하지 않는다:

- 환자 데이터·마스크·가중치를 저장소에 올리지 않는다.
- 공개 모델을 대신할 새 모델 코드를 처음부터 만들지 않는다(공식 레포를 우선 활용).
- 공유 폴더(Dropbox `PET_MRD`)를 직접 고치지 않는다.

## 2. 데이터 흐름과 위치

```
[Dropbox 공유 폴더: 원본 DICOM, 읽기 전용]
        │  복사(이동 아님)
        ▼
[워크스테이션 chlee/ 작업 영역]  DICOM → NIfTI(CTres, SUV) → 모델 입력
        │                              │
        │                              ▼
        │                       [추론 결과 마스크]  → 워크스테이션·외장하드에만 보관
        ▼
[이 저장소]  코드·설정·문서·수치 요약만
```

## 3. 단계별 산출물

| 단계 | 입력 | 출력 | 저장 위치 |
|---|---|---|---|
| ① 병변 탐지 | CTres + SUV NIfTI | 병변 마스크 NIfTI | 워크스테이션 / 외장하드 |
| ② FL-DS | 마스크 + SUV | 환자별 점수 표 | 워크스테이션 / 외장하드 |
| ③ 결합 | 점수 표 + 레지스트리 | 분석용 데이터셋 | 워크스테이션 / 외장하드 |
| ④ PFS | 분석용 데이터셋 | 모형·성능 지표 | 지표 요약만 `experiments/`(워크스테이션 로컬) |
