# 데이터 거버넌스

이 문서가 저장소의 다른 모든 문서보다 앞선다.

## 1. 원칙

1. **유출 금지.** 환자 영상·임상자료·파생물(마스크, SUV 맵, 특징값 표)은 정해진 장소 밖으로 나가지 않는다.
2. **익명성.** 식별정보(이름, 등록번호, 생년월일, 검사 일시, 주소·연락처 등)는 문서·커밋·로그·채팅 어디에도 적지 않는다.
3. **원본 불변.** 원본 DICOM 은 복사해서 쓰고 원본 폴더는 건드리지 않는다.

## 3. 가명 규칙

- 환자는 `P01`, `P02` … 로만 부른다. 순서는 원본 폴더명 정렬 순서.
- 가명 ↔ 실명 대응표는 외장하드 원본과 워크스테이션 `~/autopet3/private/` 사본 두 곳에만 둔다(2026-10-23 사용자 결정).
  저장소·Dropbox·맥 판독 폴더·채팅에 두지 않고, 내용을 화면·로그·문서에 출력하지 않는다. 확인은 줄 수·해시값으로만 한다.
- 대응표는 임상 레지스트리 결합(③단계)에만 쓴다. 결합 결과는 가명(`C###`)을 키로 하고 식별정보 열이 없는 표로 만든다.
- 파일럿 2명은 `P01`·`P02`, 외장하드 코호트는 `C001`부터(외장하드 폴더명 정렬 순서). 두 체계가 같은 환자를 가리킬 수 있으며, 그 대응도 대응표가 있는 곳에서만 확인한다.
- 원본 폴더명(등록번호·이름·검사일시)은 채팅·로그·문서에 붙이지 않는다. 전송 로그에도 가명만 남긴다.
- 원본 폴더·파일명에 식별정보가 들어 있는 경우가 있다. 경로를 문서에 적을 때는 상위 폴더까지만 적는다.

## 4. 커밋 전 점검

- `git status` 에 영상(`.dcm`, `.nii.gz`, `.mha`)·표(`.csv`, `.xlsx`)·가중치(`.pth`)·압축파일이 없는지.
- 문서·노트북 출력 셀에 환자명·등록번호·날짜가 찍히지 않았는지. 노트북은 출력 셀을 지우고 커밋한다.
