# 판정 CSV 로 autoPET 모델을 미세조정하는 방법 (계획)

후보 확인 페이지(`scripts/make_review_html.py`, [결과 확인 가이드](../guides/review-results.md) §2)에서 받은 판정 CSV 를
autoPET III LesionTracer 가중치 개선에 쓰는 경로를 정리한다. 아직 실행하지 않았다. 순서와 필요한 것을 미리 적어 둔다.

## 1. CSV 에 무엇이 들어 있나

| 열 | 뜻 | 학습에 쓰는 곳 |
|---|---|---|
| `research_id`, `record_no` | 케이스 가명, 모델 마스크의 연결성분 번호(실험 기록 표 번호와 같음) | 어느 마스크 성분인지 찾기 |
| `type` | `candidate`(모델이 낸 후보) / `added`(전문의가 추가한 누락 병변) | 아래 2절 |
| `label` | `true` / `false` / `unsure` | 성분을 남길지·지울지 |
| `x_mm`, `y_mm`, `z_mm` | RAS 좌표(Slicer 와 같은 좌표계) | 누락 병변 위치 |
| `is_index`, `memo` | index lesion 여부, 부위 메모 | 평가·보고 |
| `llm_verdict`, `llm_agree` | LLM 의견과 그에 대한 전문의 동의 | 학습에는 쓰지 않음(LLM 평가용) |

CSV 는 표 파일이라 저장소에 올리지 않는다(`.gitignore`). 워크스테이션 작업 영역에 둔다.

## 2. CSV 만으로 바로 학습할 수는 없다

nnU-Net 미세조정에는 복셀 단위 정답 마스크가 필요하다. CSV 는 후보 단위 판정이라 아래처럼 정답 마스크로 바꿔야 한다.

| 판정 | 정답 마스크로 바꾸는 방법 | 자동화 |
|---|---|---|
| 참 후보 | 모델 마스크의 그 성분을 그대로 둔다 | 가능(`case` + `record_no`) |
| 거짓 후보 | 그 성분을 지운다 | 가능 |
| 불확실 후보 | 학습에서 빼거나 손실 계산에서 무시하는 영역으로 둔다 | 가능 |
| 누락 병변 | CSV 에는 점 좌표만 있다. 그 위치의 병변 윤곽을 Slicer 에서 직접 그린다 | 수작업 |
| 참이지만 윤곽이 틀린 후보 | Slicer 에서 윤곽을 고친다 | 수작업 |

## 3. 순서

1. 판정 데이터를 모은다. 2명으로 가중치를 바꾸면 과적합만 된다. 최소 수십 명 단위가 필요하다.
   학습용과 평가용 환자를 처음부터 나누고, 평가용은 학습에 절대 넣지 않는다.
2. CSV → 정답 마스크 변환(2절의 자동 부분). 판정 CSV 가 몇 개 쌓이면 연결 스크립트로 만든다(사용자 승인 후).
3. 누락 병변과 윤곽 수정은 Slicer 에서 그린다. 결과는 `labelsTr` 형식 NIfTI 로 저장한다(저장소 밖).
4. nnU-Net 데이터셋 구성: `imagesTr/<case>_0000.nii.gz`(CTres), `<case>_0001.nii.gz`(SUV), `labelsTr/<case>.nii.gz`, `dataset.json`.
   입력은 추론 때와 똑같이 TCIA_processing 변환(AcquisitionTime 기준 SUV)을 쓴다.
5. 전처리와 학습은 공개 레포의 공식 명령을 쓴다. 새 모델 코드는 만들지 않는다.
   - autopet-3-submission README 의 Preprocessing·Extract organs(TotalSegmentator)·merge 단계가 이때 필요해진다.
     이 트레이너는 장기 분할을 보조 목표로 학습하기 때문이다.
   - 공개 가중치에서 출발하는 미세조정은 nnU-Net 의 사전학습 가중치 옵션(`nnUNetv2_train … -pretrained_weights <checkpoint>`)으로 한다.
     학습률·에폭 등 세부 설정은 그때 레포 문서를 확인해 [decisions.md](../decisions.md) 표에 한 줄로 남긴다.
6. 평가: 평가용 환자에서 공개 가중치와 미세조정 가중치를 같은 지표로 비교한다.
   지표는 병변 단위 민감도, 환자당 위양성 수, index lesion 검출 여부, FL-DS 일치도다.

## 4. 그 전에 CSV 만으로 할 수 있는 것

- 모델 성능 평가: 환자별 위양성률, 놓친 병변 수, 위양성이 몰리는 부위(메모 기준).
- 위양성 거르기 2차 분류기: 모델 후보의 수치(SUVmax·SUVpeak·부피·HU·위치)와 참/거짓 판정으로 가벼운 분류기를 학습한다.
  가중치를 바꾸지 않아 데이터가 적을 때 먼저 시도할 만하다.

## 5. 데이터 보호

- 정답 마스크·CSV·전처리 결과(`.npz`/`.npy`)·학습한 가중치는 모두 저장소에 올리지 않는다.
- 학습은 워크스테이션에서만 한다. 클라우드 학습 환경으로 옮기지 않는다.
