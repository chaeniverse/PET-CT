1. 관상면 MIP와 후보 번호

환자 오른쪽이 화면 왼쪽. 3번에서 "누락 병변 추가"를 켜면 클릭한 위치(x, y, z mm)를 기록한다.

2. 3D 보기 (3D Slicer)


  
Slicer 열기: 맥 판독 폴더(이 HTML 이 있는 폴더)에서 __CASE___Slicer열기.command 를 Finder 로 더블클릭한다. CT·SUV·병변(빨강)·후보 번호(남색 점, 카드 번호 (#기록))가 열리고, 구조 라벨 색은 L 키로 켜고 끈다.
  Slicer 에서 P 키로 누락 병변 점 찍기를 켜고 끈다. 찍은 점은 __CASE___viewer/slicer_points.csv 에 바로 써지고, 위 버튼으로 그 파일을 고르면 3번 목록에 합쳐져 CSV 에 source=slicer 로 남는다.
  후보 위치로 가려면 Slicer 의 Markups 모듈 "후보" 목록에서 번호를 누른다.

5. 후보 확인 (위에서부터 SUVmax 순) 

 
각 후보에 참 / 거짓 / 불확실 중 하나를 고르고, 점수를 준 병변이면 "index lesion"을 켠다. 빨간 윤곽 = 이 후보의 모델 마스크, 주황 윤곽 = 다른 후보, 가장자리 눈금이 가리키는 곳 = SUVmax 위치. 오른쪽 회색 칸의 LLM 의견은 참고용이다.
