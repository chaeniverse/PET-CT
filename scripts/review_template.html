FL 후보 확인

1. 관상면 MIP와 후보 번호

환자 오른쪽이 화면 왼쪽. 3번에서 "추가 모드"를 켜면 클릭한 위치(x, y, z mm)를 3번 목록에 넣는다.

2. 3D 보기 (3D Slicer)

Slicer 로 보기

  
"Slicer 로 보기" 는 맥에 PetReview 연결 앱을 한 번 만들어 두면 동작한다(결과 확인 가이드 §2-2). 처음 누를 때 Chrome 이 "PetReview.app 을 열까요?" 를 묻는다.
  연결 앱이 없으면 맥 터미널에서 petreview.sh slicer __CASE__ 를 실행한다. 같은 케이스 Slicer 가 이미 열려 있으면 새로 열지 않는다.
  Slicer 에는 CT·SUV·병변(빨강)·후보 번호(남색 점, 카드 번호 (#기록))가 4분할로, 3D 칸에는 SUV MIP 가 열린다. 도구막대 "누락 병변 찍기 (P)" 로 점 찍기를 켜고 끄고, "구조 색 (L)" 로 구조 라벨 색을 켜고 끈다.
  찍은 점은 __CASE___viewer/slicer_points.csv 에 바로 써진다(Slicer 콘솔에 "[PET-CT] … 저장"). 위 버튼으로 그 파일을 고르면 3번 목록에 합쳐지고, 거기서 참 / 거짓 / 불확실을 고른다(CSV 에 source=slicer).
  후보 위치로 가려면 Slicer 의 Markups 모듈 "후보" 목록에서 번호를 누른다.

 

 
3. 후보 밖 추가 위치 

  
모델 후보 말고 직접 고른 곳이다(MIP 클릭 또는 Slicer 점). 각 줄에 참 / 거짓 / 불확실을 고른다. 메모는 부위만 적는다.

  

  
#xyz (mm)판정메모

 

 
4. 저장

  
판정은 이 브라우저에 자동 저장된다(같은 주소로 다시 열면 이어서 할 수 있음). 끝나면 CSV 로 저장한다.
  저장 창이 뜨면 처음 한 번만 판독 폴더(autopet_review)로 가서 저장한다. 다음부터는 그 폴더에서 열린다.

  

  

 




5. 후보 확인 (위에서부터 SUVmax 순) 

 
각 후보에 참 / 거짓 / 불확실 중 하나를 고르고, 점수를 준 병변이면 "index lesion"을 켠다. 빨간 윤곽 = 이 후보의 모델 마스크, 주황 윤곽 = 다른 후보, 가장자리 눈금이 가리키는 곳 = SUVmax 위치. 오른쪽 회색 칸의 LLM 의견은 참고용이다.
